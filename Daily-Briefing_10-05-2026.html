📚 30-Min Learning Focus
💻 Today: JavaScript — DOM Manipulation & Event Handling

DOM manipulation is the gateway skill that makes JavaScript real. Once you can grab an element, change its content, and respond to a click — you can build anything interactive on the web. This is where JavaScript stops being abstract and starts being genuinely powerful.

Your 30-Minute Exercise: Build a simple to-do list using only vanilla JavaScript (no libraries). Use document.querySelector() to grab elements, addEventListener() to listen for button clicks, and createElement() + appendChild() to add items to a list. Add a “Done” button per item that removes it. That’s it — but you’ll have touched the four most important DOM methods in one session.

Why this matters for you: Every web project — Explore Invergordon, the Meal App, OpenClaw — relies on this foundation. Fluent DOM skills also make you a better AI tool user: you’ll understand what Claude is building when it generates JS for you, and you’ll be able to spot and fix bugs.
