📊 Skill Focus — Data Analysis
⚡ Today’s Practical Tip
Master the “So What?” Test. After every analysis, ask yourself: “So what does this mean, and what should we do about it?” Employers don’t want raw numbers — they want action insights. Practise translating a metric (e.g. “engagement dropped 12%”) into a clear recommendation (“We should test posting at 9am instead of 12pm based on our audience’s timezone data”).
Why it matters for you: Community managers and content roles in crypto increasingly require data literacy. Being able to pull Discord/Twitter analytics, spot trends, and report them in plain English sets you apart from candidates who can only manage community without measuring it.
🔧 Tools to learn: Google Sheets (AVERAGEIF, VLOOKUP) → Metabase (free, no-code dashboards) → Python pandas (when ready). Start with Sheets today.

📚 30-Min Learning Focus — Data Analysis
Today’s Exercise: Community Metrics Dashboard in Google Sheets
You manage a Discord community for a crypto project. You’ve been given a week’s worth of engagement data. Your job: build a simple analysis sheet and extract 3 actionable insights.
⏱ 30-Minute Structured Session:
Min 1–5: Open Google Sheets. Create headers: Date | New Members | Messages | Active Users | Reactions. Enter 7 rows of realistic data.
Min 6–12: Add a Totals row (SUM). Add an Averages row (AVERAGE). Add an “Engagement Rate” column = Messages / Active Users.
Min 13–20: Select your data and insert a Line Chart. Label it “Weekly Discord Activity.” Apply clean colours.
Min 21–28: Write 3 bullet-point observations above the table: Best day? Worst day? What would you recommend the team change and why?
Min 29–30: Screenshot the sheet. This is now a portfolio piece you can reference in applications.
💡 Real-world value: This is exactly the weekly report community managers send to crypto project leads. One session = one real, demonstrable skill.
