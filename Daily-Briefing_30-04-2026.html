📚 30-Minute Learning Focus — JavaScript
Today: JavaScript Fundamentals for Automation & AI Tool Building

JavaScript is the one programming language that runs everywhere — browsers, servers (Node.js), and AI automation pipelines. You don’t need to master it; you need to be dangerous with it. Today’s goal is to write one working fetch() call that pulls live data from an API.

  • Action A (Highest Impact — 30 min): Build a Live Data Fetcher. Open browser console (F12 → Console tab). Type: fetch("https://api.open-meteo.com/v1/forecast?latitude=57.68&longitude=-4.17¤t=temperature_2m&timezone=Europe/London").then(r=>r.json()).then(d=>console.log(d.current.temperature_2m+"C")) — press Enter. You just fetched live Invergordon weather with JavaScript. What you learn: async fetch, Promises, JSON parsing — the exact pattern used in AI tool integrations.
  • Action B (High Impact — 30 min): Build a Mini Briefing Widget. Open a new HTML file in any text editor. Create a <div id="output"> and write a script that fetches Open-Meteo and writes the temperature into that div. Save it, open in browser. You now have a working live-data web page. What you learn: DOM manipulation, innerHTML, async/await — directly transferable to building AI-powered client tools.
  • Action C (Foundation — 30 min): JavaScript.info Chapter 1. Go to javascript.info and read “The JavaScript language → JavaScript Fundamentals” chapters 1-3. These cover variables, data types, and operators. The site is completely free, no account needed, and is considered the best JS reference online. What you learn: the mental model for reading and writing JS confidently.

Free Resources — 30-min reads: JavaScript.info (javascript.info) — completely free, best-in-class JS tutorial. The Open-Meteo API (open-meteo.com) — free, no API key, CORS-friendly. Perfect for practising fetch() without account setup friction.
